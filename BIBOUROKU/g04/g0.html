ランプ点滅

スイッチを押すたびに点滅を繰り返す論理を作ります。
チャタリング除去 で作った論理譜を手続きに利用します。
SAMPLE.L
{ =============================================== }
{      ランプ点滅                                 }
{ =============================================== }
logicname sample

{ =============================================== }
{      手続き譜                                   }
{ =============================================== }
procedure sw
input  swa,swb;
output q;
bitr   regq;

   if (swb)
      regq=0;
   else
      if (swa)
         regq=1;
      else
         regq=regq;
      endif
   endif

   q=regq;
endp

{ =============================================== }
{      実効譜                                     }
{ =============================================== }
entity main
input  Reset;
input  swa,swb;
output lamp;
bitn   q;
bitr   on[2];
bitr   reglamp[2];

   if (!Reset)
      q=sw(swa,swb);

      if (q)
         if (on==0)
            on=1;
         else
            on=2;
         endif
      else
         on=0;
      endif

      if (on.0)
         reglamp=reglamp+1;
      else
         reglamp=reglamp;
      endif
   endif

   lamp=reglamp.0;
ende

{ =============================================== }
{      機能実行譜                                 }
{ =============================================== }
entity sim
output Reset;
output swa,swb;
output lamp;
bitr   tc[5];
input  simres;

   simres=0; {←LSIMを使うとき以外は外すか注釈にする。}
   part main(Reset,swa,swb,lamp)
   if (!simres) tc=tc+1; endif

   switch(tc)
      case 0:  Reset=1;
      case 1:  Reset=1;
      case 2:  Reset=1;
      case 3:  swa=1;
      case 6:  swb=1;
      case 9:  swa=1;
      case 12: swb=1;
      case 15: swa=1;
      case 18: swb=1;
      case 21: swa=1;
      case 24: swb=1;
      case 27: swa=1;
      case 30: swb=1;
   endswitch

ende
endlogic

上のe1.vとs1.vをPLDメーカの開発ツールで検証する と下の結果が得られました。 e1.vは検証用のものです、チップ化はe0.vで行います 。

LSIM用の検証用の論理譜はt1.simです、これには検証 用の論理譜が追加されています。 全信号の動きは下のようになっています、_n34より下 が検証論理の信号です。

L譜ではinputやoutputなどの端子信号以外の信号名は コンパイラが自動的に生成した信号名に割り当てられ ます。
これらは選択機能の -log を指定してコンパイルする とLDC.LOGが作られるので、その中のentity simを処 理した「LSIM FILE OUT」に割り当てが書かれていま す。
例えば、スイッチを押すたびに、1CLKだけ1になる on.0は_n7に割り当てられています。
