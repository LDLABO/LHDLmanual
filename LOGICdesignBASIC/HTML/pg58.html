　リスト53　レジスタ0
 　  

if (RESET)
   reg0R=0;
else
   if (code27p|code29p)
      if (code27p) reg0R=reg0R＞＞PORT1ADD.0:3; endif
      if (code29p) reg0R=reg0R＜＜PORT1ADD.0:3; endif
   else
      if (RW)
         switch(PORT0ADD)
            case 0:  reg0R=PORT0OUT;
            default: reg0R=reg0R;
         endswitch
      else
         reg0R=reg0R;
      endif
   endif
endif
 　 

リスト53 はレジスタ 0 の reg0R を示し ます。レジスタ 0 を変更する命令指標は次 のものがあります。

  • code27p : SLA r0,n
  • code29p : SRA r0,n

レジスタ枠 0 で示されるレジスタに対す る書き込み指標は RW です、この値が1 で PORT0ADD の値が0 のときはレジスタ 0 に 対する書き込みなのでレジスタ枠 0 で示さ れるレジスタへの書き込み値の PORT0OUT の値をレジスタ0 を示す reg0R に記憶します。
