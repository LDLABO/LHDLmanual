　リスト83　命令解読
 　  

{ PPU 命令解読 }
switch(DATAINb.24:31)
   case 21: codeb21p=1;   { ADD rx,n }
   case 19: codeb19p=1;   { CP rx,n }
endswitch

　　　レジスタR0 R5 R6 R7

　リスト84　レジスタR0 R5 R6 R7
 　  

reg0Rb=SCLK;

if (RESET)
   reg5Rb=0;
   reg6Rb=0;
   reg7Rb=0;
else
   if (reg7R)
      reg5Rb=reg5R.0:3;
      reg6Rb=reg4R.0:3;
      reg7Rb=reg2R.0:3;
   else
      reg5Rb=reg5Rb;
      reg6Rb=reg6Rb;
      reg7Rb=reg7Rb;
   endif
endif
 　 

リスト84 の reg0Rb は SCLK をプログラムから読み取れるようにそのまま代入しています。 reg7R はBCD 変換部のプロセッサの R7 で変換の終了を示していますが reg7R が1 のときにBCD の値をLED 表示を担当する本プロセッサの reg5Rb , reg6Rb , reg7Rb に記憶します。

  • reg5Rb は 1 の位の値
  • reg6Rb は 10 の位の値
  • reg7Rb は 100 の位の値

　　　レジスタR1

　リスト85　レジスタR1
 　  

if (RESET)
   reg1Rb=0;
else
   if (codeb21p)            { ADD r1,n }
      reg1Rb=opbout.0:1;
   else
      if (RWb)
         switch(PORT0ADDb)
            case 1:  reg1Rb=PORT0OUTb.0:1;
            default: reg1Rb=reg1Rb;
         endswitch
      else
         reg1Rb=reg1Rb;
      endif
   endif
endif
 　 

リスト85 の reg1Rb は3 ビットの桁計数で表示する桁をどこにするかを示しています。本レジスタは ADD 命令の対象レジスタになっているので ADD 命令が実行中の codeb21p が1 のときに演算器の出力の opbout を記憶します。
