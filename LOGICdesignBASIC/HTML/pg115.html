　　　ModelSim

ModelSim を使った 図5.39 と同じ実行位置の画面が 図5.40 です。全部は MS06E09A .lzh を展開して見て下さい。


図5.40 ModelSim の画面
    　　　 

ModelSim では初期化されない記憶信号は 図5.41 のように値が不定になっています。 リスト109 では tc が 5 より小さいときに node_RESET を 1 にしているので tc が不定だと検証論理と設計論理の初期化ができません。


図5.41 ModelSim の初期値
    　　　 

ModelSim で検証結果を見られるようにするためには リスト109 の 行8 に input simres を追加して 行26 の tc=tc+1 を if (!simres) tc=tc+1; endif に変更します。
