　　　命令解読

リスト46 は命令種別の instcode から命令指標を作っています。

　リスト46　命令解読
 　  

switch(instcode)
   case 1: inst1no=1;      { JP  n'n }
   case 2: inst2no=1;      { JZ  n'n }
   case 3: inst3no=1;      { LD  r0,r1 }
   case 4: inst4no=1;      { LD  r0,n }
   case 5: inst5no=1;      { AND r0,r1 }
   case 6: inst6no=1;      { OR  r0,r1 }
   case 7: inst7no=1;      { AND r0,n }
   case 8: inst8no=1;      { OR  r0,n }
   case 9: inst9no=1;      { USR r0,r1,r2 }
   case 10: inst10no=1;    { JNZ n'n }
   case 11: inst11no=1;    { LD  r0,pc }
   case 12: inst12no=1;    { LD  pc,r0 }
   case 13: inst13no=1;    { XOR r0,n }
   case 14: inst14no=1;    { XOR r0,r1 }
endswitch
 　 
図4.9 最小構成
    　　　 

プロセッサの基本部分が持っているのはフラグZ だけです。実際に利用するには最低でもレジスタ が１個は必要です、図4.9 がほぼ最小構成ですがレ ジスタはR0 の1 本だけです。フラグはプロセッ サの基本部分に含まれる論理演算命令の結果だけ が反映されるZ と追加した命令で使うためのFZ があります。


　　　書き込み値

リスト47 はレジスタ枠0 で示されるレジスタへの書き込み値の PORT0OUT を作っています。命令指標については リスト46 を見て下さい。

　リスト47　書き込み値
 　  

if (inst3no) PORT0OUT=PORT1IN; endif                     { LD r0,r1 }
if (inst4no) PORT0OUT=immcode; endif                     { LD r0,n }

if (inst5no|inst6no|inst7no|inst8no|inst13no|inst14no)
   PORT0OUT=opout;
endif

if (inst11no) PORT0OUT=regPC.0:7+2; endif                { LD r0,pc }
 　 

  • 1 番目の if 文はレジスタ枠1 で指定されるレジスタの値を代入しています。
  • 2 番目の if 文は即値を代入しています。
  • 3 番目の if 文は論理演算の値を代入しています。
  • 4 番目の if 文は「戻り値」のプログラムカウンタの値を代入しています。
