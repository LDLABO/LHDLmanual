リスト109 が表示器の機能実行譜の全文です。

  • 行1 の entity sim が機能実行譜のはじまりを示します。
  • 行2〜7 が検査端子を示します。
  • 行9〜14 が内部信号を示します。
  • 行16〜17 が検査論理の信号の引き出し端子です。
  • 行19〜20 が実効譜を導入しています。
  • 行22〜63 が検査論理です。

行22 で RESET=node_RESET と書いてある理由は RESET は出力端子なので論理で参照することができませんから論理では変わりに node_RESET の信号で利用して node_RESET を RESET に代入しています。

行25 で node_SCLK に周期的な信号を供給するために tc.4 を代入しています。 tc は無制御の計数器なので機能実行の始まりと同時に連続して計数しています。

行29〜42 は node_KETA が 0 になったときに sclkp.0 に1CLKの起点を出します。

行44〜52 は sclkp.0 が 1 になったのを受けて count を計数します。

図5.38 が実行結果の一部ですが実際の閲覧プログラムの画面は 図5.39 です。 この画面を前後左右に移動しながら実行の様子を確認していきます。

count は 0 から始まって 15 になり、また 0 に戻るのが tc が 10 進数で 4057 まで計数したときです。

信号値の変化を基(もと)にした相対的な実行位置は count によって得ますが実行が始まってからの絶対的な実行位置は tc から得ます。
