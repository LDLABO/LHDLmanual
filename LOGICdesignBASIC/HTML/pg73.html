　　　演算器

本プロセッサの演算器は CP 命令で使う一致検出のための比較と SUB 命令で使う減算を実行します。 リスト78 は演算器本体と演算器の2 本の入力とフラグの論理です 図4.25 のように構成しています。

　リスト78　演算器とその周辺
 　  

{ PPU 演算器 }
if (code19p) opout.0=opina==opinb; endif
if (code24p) opout=opina-opinb; endif

{ PPU 演算器入力a }
switch(PORT0ADD)
   case 1: opina=reg1R;
   case 2: opina=reg2R;
   case 4: opina=reg4R;
   case 5: opina=reg5R;
endswitch

{ PPU 演算器入力b }
if (code24p)
   switch(PORT1ADD)
      case 3: opinb=reg3R;
   endswitch
endif

if (code19p) opinb=DATAIN.8:15; endif

{ PPU フラグFZ }
if (RESET)
   flgZ=0;
else
   if (code19p)
      switch(DATAIN.16:23)
         case 1:  flgZ=opout.0;   { CP r1,n }
         case 2:  flgZ=opout.0;   { CP r2,n }
         default: flgZ=flgZ;
      endswitch
   else
      flgZ=flgZ;
   endif
endif
 　 
図4.25 演算部の構成
    　　　 
  • code19p : CP 命令
  • code24p : SUB 命令
  • DATAIN.8:15 : 即値
  • DATAIN.16:23 : レジスタ枠0 のレジスタ番号
  • PORT0ADD : レジスタ枠0 のレジスタ番号
  • PORT1ADD : レジスタ枠1 のレジスタ番号

ALU は Arithmetic Logic Unit の略です、算術演算と論理演算を行います。本プロセッサの演算器は算術演 算と比較だけの簡単なものですがALU を意識して作ってみました、論理演算はプロセッサの基本部分の方に 持っています。ALU はプロセッサの中心に位置する部分なので複雑なものに思われがちですが演算の対象にな る2 本の入力の opina と opinb と演算の種類を決める信号の code19p と code24p を入力にして opout を出力にする真理値表です。他のプロセッサの場合も演算の種類が多くなっている程度で基本的な構造は同じですか ら論理設計に大差はないと思います。ALU を意識したので演算の入力を opina と opinb に出力を opout に集約しましたが、そのようにしないこともあります。PLD に作られるプロセッサのおかれる状況は様々なので一 般的なコンピュータの設計手法にとらわれる必要はあまりないような感じはしています。
