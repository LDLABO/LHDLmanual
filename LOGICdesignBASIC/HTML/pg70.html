　　　除算器

リスト69 の divout=divina/divinb の部分は言語が演算子で提供する記憶形式の8 ビットの除算を使ってプロセッサの除算命令を実現しています。除算命令は DIV r0,n なので入力 a はレジスタ R0 から入力 b は即値から値を持ってきます。

　リスト69　除算の実行
 　  

{ PPU 除算器 }
if (!code23p)
   divout=divina/divinb;
endif

{ PPU 除算器入力a }
if (code23p)
   switch(PORT0ADD)
      case 0:  divina=PORT0IN;
      default: divina=divina;
   endswitch
else
   divina=divina;
endif

{ PPU 除算器入力b }
if (code23p)
   divinb=DATAIN.8:15;
else
   divinb=divinb;
endif

{ PPU 1 レジスタFE }
flgE=divout.8;
 　 

この論理を実行した様子が 図4.23 です。 code23p が1 のときに除算器が初期化されて13 個のCLK を使って divout.8 が1 のときに結果が出ています。

図4.23 除算の実行
