　リスト23　8ビットの除算器(記憶)
 　  

entity main
input  RESET;
input  A[8];
input  B[8];
output C[8];
output READY;

bitr   p[16];
bitr   q[8];
bitr   count[4];
bitn   r[9];
bitn   np[9];
bitn   nb[9];
bitn   stop;

   C=q;
   READY=stop;

   np.0:7=p.8:15;
   nb.0:7=B;

   if (RESET)
      p.0:7=A;
   else
      if (stop)
         p=p;
      else
         if (r.8)
            p.1:15=p.0:14;
         else
            p.9:15=r.0:6;
            p.1:8=p.0:7;
         endif
      endif
   endif

   r=np-nb;

   if (RESET)
      q=0;
   else
      if (stop)
         q=q;
      else
         if (r.8)
            q.1:7=q.0:6;
         else
            q.0=1;
            q.1:7=q.0:6;
         endif
      endif
   endif

   if (RESET)
      count=0;
   else
      if (stop)
         count=count;
      else
         count=count+1;
      endif
   endif

   if (count==9) stop=1; endif

図3.33 リスト23の実行
 　　　    

記憶式の除算器は比較器と減算器とシフトレジスタ からできていますが比較器と減算器はひとつの論理で 兼用しています、減算器は加算器の入力を変えたもの です、加算器は簡単な真理値表に還元されます、シフ トレジスタも簡単な記憶の一種です、真理値表と記憶 でどのような論理も構成できることが分かると思い ます。
