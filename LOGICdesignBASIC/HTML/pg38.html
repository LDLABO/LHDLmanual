リスト29 は point で指定する隣り合う番地のメ モリを比較して小さい番地のメモリのデータが大き いときは chg を1 にします。


リスト30 はメモリの交換を次のように示します。

　リスト30　交換メモリ位置指示
 　  

if (state1p)
   switch(point)
      case 0: if (chg) swap01p=1; endif
      case 1: if (chg) swap12p=1; endif
      case 2: if (chg) swap23p=1; endif
      case 3: if (chg) swap34p=1; endif
      case 4: if (chg) swap45p=1; endif
      case 5: if (chg) swap56p=1; endif
      case 6: if (chg) swap67p=1; endif
      case 7: if (chg) swap78p=1; endif
      case 8: if (chg) swap89p=1; endif
   endswitch
endif
 　 
  • swap01p が1 : 番地0 と番地1 を交換します。
  • swap12p が1 : 番地1 と番地2 を交換します。
  • swap23p が1 : 番地2 と番地3 を交換します。
  • swap34p が1 : 番地3 と番地4 を交換します。
  • swap45p が1 : 番地4 と番地5 を交換します。
  • swap56p が1 : 番地5 と番地6 を交換します。
  • swap67p が1 : 番地6 と番地7 を交換します。
  • swap78p が1 : 番地7 と番地8 を交換します。
  • swap89p が1 : 番地8 と番地9 を交換します。
