if (mode)

   SCLK=tc.4;   { 表示器 }

表示の実行ではキー入力を使って実行していたときの SCLK では短いので表示の実行を確認したいときだけ リスト141 のように mode を 0 にして長い SCLK のほうを使います。

この実行位置は リスト140 の端末の外からの端末のメモリへの書き込みの後ですからメモリには上の番地から 1〜8 が書き込まれています、表示は上の桁から 1〜8 を表示します。その数値を表示するためのセグメントの表示値は表示器の論理の リスト108 を見て下さい。 図5.71 は KETAOUT が 1 なので 1 番目の桁のところを実行している様子ですが SEGOUT はセグメントの表示値が 6 なので数値の 1 を表示しています。この位置から上流には上位の桁の実行結果がありますからメモリに書き込まれた値を表示しているかどうかを確認します。
