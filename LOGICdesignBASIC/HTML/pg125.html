　　端末

端末は表示器とキーボードと8 個の4 ビットのメモリを持っています。キーボードから入力されたデータは表 示器に表示されると共に端末のメモリに蓄積されます。キーが押されると端末の外に対してデータがあることを 知らせます。外部から端末のメモリに書き込むことで表示を変更することができます。

　　　チップ概観

チップの概観は 図5.53 のようになります。

  • RESET : チップを初期化します。
  • SCLK : 表示器とキーボードを駆動するCLK です。
  • ADD[3] : 端末の持っているデータを読み出す番地です。
  • SET : キーが押されたことを知らせます。
  • OFF : キーがひとつも押されていないことを知らせます。
  • TAKE : SET を解除します。
  • SEGOUT[7] : 表示器のセグメント値です。
  • KETAOUT[8] : 表示器の桁値です。
  • XSEL[4] : キーボードの列の駆動値です。
  • YIN[4] : キーボードの行入力です。
  • EXTADD[3] : 端末に書き込むための番地です。
  • EXTDATA[4] : 端末に書き込むデータです。
  • EXTWP : 端末に書き込む指標です。
  • DATA[4] : ADD[3] で読み出したデータです。
  • FUNC[3] : 機能キーの値を示します。
