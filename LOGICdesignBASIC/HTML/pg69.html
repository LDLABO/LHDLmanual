図4.22 プロセッサの実行
    　　　 

　　　プロセッサ基本部分の導入

リスト66 はBCD 変換器のBCD 変換に関わるプロセッサの部分です。このプロセッサのプログラムは リスト64 ですがこれをアセンブルしてインテルへクスデータの bcda.hex を作りこれを リスト67A で導入しています。チップの初期化の直後の様子は 図4.22 のようになります。


　リスト66　プロセッサ基本部分の導入
 　  

int_ppu=ppu(RESET,DATAIN,PORT0IN,PORT1IN,INT);

int_ppu.49=1;

ADDRESS=int_ppu.0:7;
PORT0ADD=int_ppu.16:23;
PORT1ADD=int_ppu.24:31;
PORT0OUT=int_ppu.40:47;
RW=int_ppu.48;
 　 
　リスト67a　プログラムの導入
 　  

preparation codegendw(ADDRESS,datain,bcda)

DATAIN.0:7  =datain.24:31;
DATAIN.8:15 =datain.16:23;
DATAIN.16:23=datain.8:15;
DATAIN.24:31=datain.0:7;
 　 

リスト67A の codegendw 文の bcda.hex のはじめの部分は次のようなものです。 


:10000400170064000712010002000200030201004D
:1000140013010000071101000A000E001301010082

これが リスト67B の switch 文に展開されます。

　リスト67b　プログラムの導入
 　  

switch(ADDRESS)
   case 0x1    : datain = 0x00640017; {4}
   case 0x2    : datain = 0x00011207; {8}
   case 0x3    : datain = 0x00020002; {c}

   case 0x30   : datain = 0x002f0002; {c0}
   case 0x31   : datain = 0x00000707; {c4}
   case 0x32   : datain = 0x00010001; {c8}
endswitch
 　 

リスト67B はインテルへクスデータを32 ビットの信号の下位のバイトから配置していますが本プロセッサ では上位バイトから配置する必要があるので リスト67A では datain で受けて DATAIN で配置をやり直しています。


　　　命令解読
　リスト68　命令解読
 　  

switch(DATAIN.24:31)
   case 19: code19p=1;   { CP  r0,n }
   case 23: code23p=1;   { DIV r0,n }
   case 24: code24p=1;   { SUB r0,n }
   case 27: code27p=1;   { SLA r0,n }
endswitch
 　 

リスト68 はプロセッサの基本部分に追加した命令の解読の 論理です。
