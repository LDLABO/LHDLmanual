　　表示器の論理

7 セグメントLED を時分割で表示する8 桁の表示器を駆動する論理を作ります。一部を抜粋して説明します ので全部は LDL06E09A.pdf を見て下さい。

　　　チップ概観

図5.28 チップ概観
    　　　 

チップの概観は 図5.28 のようになります。

  • RESET : チップを初期化します。
  • SCLK : 8 桁表示の桁を進行するCLK で1CLK で一桁ず つ点灯します。
  • SEGOUT[7] : 7 セグメントのLED のセグメントを駆動します。
  • KETAOUT[8] : 7 セグメントのLED の共通端子を駆動します。
  • KETA[3] : 本チップは表示するデータを記憶しないので外部から逐次入力しています。本端子は入力する BCD 値の桁を示しています。
  • DATA[4] : KETA[3] で指定する桁のBCD 値を入力します。

　　　表示方法

図5.29 表示方法
    　　　 

図5.25 のように8 個の7 セグメントのLED をセグメントと桁に分けて 図5.29 のように駆動します。 図5.22 の a〜g がセグメント端子で COM が桁端子です。

  • 8 個の7 セグメントLED の桁端子を時分割で駆動すること で8 個の7 セグメントLED を点灯します。
  • 8 個の7 セグメントLED の桁端子をひとつも駆動しないこ とで8 個の7 セグメントLED を消灯します。

すべての7 セグメントLED のセグメント端子は共通になってい るので8 個の7 セグメントLED が全部消灯する時間を作って、そこでセグメント端子の駆動値を変えることで 表示がちらつかないようにします。

7 セグメントLED の時分割の表示方法とは、ひとつの桁だけを 図5.29 のように全桁の非表示期間をはさ挟みな がら連続して桁と表示値を変えながら順番に駆動することです。


　　　SCLK行程

SCLK は 図5.29 のように表示器の桁を駆動しています。内容はキーボードの列駆動の場合と同じなのでリストと行程図はそちらを見てください。 駆動の起点は SCLK が0 から1 になったところです。 SCLK の変化を2ビットの値にして捉(とら)えようとしたのが リスト92 の SCLK 行程の sclkp です、意味は 図5.12 のようになります。
