No.116
　
　　メモリ

本メモリは A と B の独立した番地入力を持つ2 本の読み出し出力があります。書き込みも独立した番地入力 を持ち「せり上がり書き込み」と「番地指定書き込み」の2 系統で行います。読み出しと書き込みを同時に行う ことができます。

　　　チップ概観

図5.42 チップ概観
    　　　 
  • RESET : チップを初期化します。
  • ADDA[3] : 読み出し番地のA です。
  • ADDB[3] : 読み出し番地のB です。
  • ADDC[3] : 書き込み番地のC です。
  • DATAIN[4] : せり上がり書き込みのデータです。
  • DATACIN[4] : 番地指定書き込みのデータです。
  • WP : せり上がり書き込みの指標です。
  • WCP : 番地指定書き込みの指標です。
  • DATAAOUT[4] : 読み出しデータのA です。
  • DATABOUT[4] : 読み出しデータのB です。

　　　チップ内部構成

図5.43 チップ内部構成
    　　　 

チップの内部の構成は 図5.43 のようになっています。 memory0 から memory7 の4 ビットのメモリを番地の 0〜7 で読み書きします。

memory□ は1番地分を手続きの MEMORY に作って8個を引用します。

書き込みが「せり上がり書き込み」になるか「番地指定書き込み」になるかは WP と WCP で決まりますが mode はそれを記憶しています。

せり上がり書き込みでは memory0 には DATAIN が記憶されます。 memory1〜memory7 には下位の memory□ のデータが記憶されるのでデータが下位のメモリからせり上がってくるように記憶されます。
