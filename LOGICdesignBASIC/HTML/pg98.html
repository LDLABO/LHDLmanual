　　　キートップと番号の割り当て

キートップで示されるキーを押したときに Q に表れる値は 図5.11 のように決められます。

図5.10 キートップと番号の割り当て
    　　　 
    　　　 
　　　SCLK 行程

SCLK は 図5.10 のようにキーボードを駆動しています。駆動の起点は SCLK が0 から1 になったところです。 SCLK の変化を2 ビットの値にして 捉(とら)えようとしたのが リスト92 の SCLK 行程の sclkp です、意味は 図5.12 のようになります。

　リスト92　SCLK行程
 　  

if (RESET)
   sclkp=0;
else
   if (SCLK)
      switch(sclkp)
         case 0: sclkp=1;
         case 1: sclkp=2;
         default: sclkp=sclkp;
      endswitch
   else
      sclkp=0;
   endif
endif
 　 
図5.12 SCLK行程
    　　　 
　　　駆動計数

　リスト93　駆動計数
 　  

if (RESET)
   count=0;
else
   if (sclkp.0)
      if (count==3)
         count=0;
      else
         count=count+1;
      endif
   else
      count=count;
   endif
endif
 　 

リスト93 の count は 図5.10 のようにキーボードの列を駆動する計数です。 計数の起点は SCLK が0 から1 になところで sclkp.0 が1 のところは 図5.12 の SCLK 行程の 1 のところです。今回のキーボードは列が4 本なので count は 0〜3 までの値になります。
