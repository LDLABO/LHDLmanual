● XOR r0,n

 　  

macro     XOR R,NUMBER
   db 0dh,#0,#1&0ffh,(#1>>8)&0ffh
endm
 　 

定義の内容は LD r0,r1 とほぼ同じですがレジスタ枠1 が8 ビットの即値になっています。


● XOR r0,r1

 　  

macro     XOR R,R
   db 0eh,#0,#1,0
endm
 　 

定義の内容は LD r0,r1 とほぼ同じです。


　　　プロセッサ基本論理

プロセッサの基本部分の論理を抜粋して説明します。全部は PPU_L.pdf を見て下さい。

　　　プログラムカウンタ

リスト43 はプログラムカウンタの論理です、プログラムカウンタは分岐命令がなければ regPC=regPC+1 になります。分岐命令があれば regPC=jmpcode になります。割り込みがあったときは regPC.0:7=PORT0IN になります。プログラムカウンタの動きは 図4.7 の ADDRESS を見て下さい。

　リスト43　プログラムカウンタ
 　  

if (RESET)
   regPC=0;
else
   if (INT)
      regPC.0:7=PORT0IN;
   else
      if (inst1no)                    { JP n'n }
         regPC=jmpcode;
      else
         if (inst2no)                 { JZ n'n }
            if (flgZ)
               regPC=jmpcode;
            else
               regPC=regPC+1;
            endif
         else
            if (inst10no)             { JNZ n'n }
               if (!flgZ)
                  regPC=jmpcode;
               else
                  regPC=regPC+1;
               endif
            else
               if (inst12no)          { LD pc,r0 }
                  regPC.0:7=PORT0IN;
               else
                  regPC=regPC+1;
               endif
            endif
         endif
      endif
   endif
endif
