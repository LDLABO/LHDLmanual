　　　端末書き込み行程

　リスト170　端末書き込み行程
 　  

if (RESET)
   dep=0;
else
   switch(termwritestart)
      case 2:
         switch(dep)
            case 2: dep=0;
            default: dep=dep+1;
         endswitch
   endswitch
endif
 　 

リスト170 の端末書き込み行程の dep は端末のメモリへの1番地分の書き込みの行程です。 図5.108 のように 3CLK の長さになっています。


図5.108　端末書き込み行程
    　　　 

端末書き込み開始終了行程の termwritestart が 2 のときに、この行程が動きます。 図5.107 の端末書き込み指標の dspbcdwp は本行程が 0 で termwritestart が 2 のときに 1 になります。

　　　端末要求行程

　リスト171　端末要求行程
 　  

if (RESET)
   setseq=0;
else
   switch(setseq)
      case 0:
         if (set) setseq=1; endif
      case 1:
         if (take)
            setseq=2;
         else
            setseq=setseq;
         endif
      case 2: setseq=4;
      case 4:
         if (set)
            setseq=setseq;
         else
            setseq=0;
         endif
   endswitch
endif
 　 

リスト171 の端末要求行程の setseq は端末が入力のあったことを示したときに対応する行程です。 12345678/ の入力があると 図5.109 のように端末の set が 1 になって数値入力があったことが知らされます。


図5.109　端末要求行程
    　　　 

電卓の論理は端末のメモリからBCD 値を読み出して2進数に変換してから take を 1 にします。端末の論理はこれを受けて set を 1 から 0 に戻します。端末要求行程の setseq はこれを受けて 図5.110 のように行程を 4 から 0 に戻します。
