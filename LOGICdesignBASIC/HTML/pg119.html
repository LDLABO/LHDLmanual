　　　メモリ選択

　リスト116　メモリ選択
 　  

switch(mode)
   case 1:
      mcs=0xff;
   case 2:
      switch(regADDC)
         case 0: mcs.0=1;
         case 1: mcs.1=1;
         case 2: mcs.2=1;
         case 3: mcs.3=1;
         case 4: mcs.4=1;
         case 5: mcs.5=1;
         case 6: mcs.6=1;
         case 7: mcs.7=1;
      endswitch
endswitch
 　 

リスト116 のメモリ選択の mcs.0〜mcs.7 は書き込まれるメモリを示します。

  • 書き込み種別の mode が 1 のときは「せり上がり書き込み」で 図5.48 のようにすべてのメモリに書き込むので mcs.0〜mcs.7 を 1 にしています。
  • 書き込み種別の mode が 2 のときは「番地指定書き込み」で regADDC で示す番地のメモリの mcs だけを 1 にします。

　リスト119　メモリ読み出しデータ
 　  

switch(ADDA)
   case 0: DATAAOUT=memory0;
   case 1: DATAAOUT=memory1;
   case 2: DATAAOUT=memory2;
   case 3: DATAAOUT=memory3;
   case 4: DATAAOUT=memory4;
   case 5: DATAAOUT=memory5;
   case 6: DATAAOUT=memory6;
   case 7: DATAAOUT=memory7;
endswitch

switch(ADDB)
   case 0: DATABOUT=memory0;
   case 1: DATABOUT=memory1;
   case 2: DATABOUT=memory2;
   case 3: DATABOUT=memory3;
   case 4: DATABOUT=memory4;
   case 5: DATABOUT=memory5;
   case 6: DATABOUT=memory6;
   case 7: DATABOUT=memory7;
endswitch
 　 
　　　メモリ書き込みデータ

リスト117 はメモリ書き込みデータの writedata0p〜writedata7p です。

  • 書き込み種別の mode が 1 のときは「せり上がり書き込み」なので 図5.48 になるような代入をしています。
  • 書き込み種別の mode が 2 のときは「番地指定書き込み」なのですべてのメモリ書き込みデータに DATACIN を代入しています。
　　　メモリの書き込み番地

リスト118 のメモリの書き込み番地の regADDC は「番地指定書き込み」のときのメモリの番地を示します。 書き込み行程の wp が 0 から変化するときに ADDC の値を記憶しています。

　　　メモリ読み出しデータ

リスト119 のメモリ読み出しデータの DATAAOUT と DATABOUT はそれぞれが独立した番地指定の ADDA と ADDB を持つメモリの読み出し値を示します。
