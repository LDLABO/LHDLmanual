図3.35 メモリの構成
 　　　    

図3.35 のように番地の隣り合うメモリだけでデータの交換できる8 ビット のメモリを10 個で構成します。

  • 小さい番地から連続した2 個のメモリのデータを比較して小さい番地 のメモリのデータの方が大きかったらデータを交換します。
  • これを番地を増やしながら番地8 と番地9 のメモリまで行います、こ こで番地0 の最初から一回も交換が行われていなかったら並び替えは 完了です。
  • 一回でも交換が行われていたらメモリのデータは番地0 から小さい順 番に整列していなかったことになります。


　　　メモリ

論理設計でメモリを作って使う場合にはデータバスがないのでチップの内部の複数の論理からメモリの値を制 限なく参照することができます。アドレスバスもないので複数のメモリの値を同時に参照することもできます。 今回のように並び替えの機能を追加するなども簡単に行えます。

　リスト25　並び替え用のメモリ
 　  

if (reset)
   memory0d=0;
else
   if (cs)
      if (address==0)
         if (we)
            memory0d=datain;
         else
            memory0d=memory0d;
         endif
      else
         memory0d=memory0d;
      endif
   else
      if (swap01p)
         memory0d=memory1d;
      else
         memory0d=memory0d;
      endif
   endif
endif
 　 

リスト25 は並び替え専用のメモリの番地1 個分です。

  • address==0 は0 番地のメモリを示します。
  • swap01p はメモリデータを交換します。
  • reset でメモリに初期値を与えることができます。

cs が1 で address が0 で we が1 のときに datain の値が 記憶されます。 cs が0 のときにメモリデータの交換が行われるので並び替 え中に外からメモリに書き込むと書き込みが優先されて並び替 えは行われませんが並び替えの結果には影響を与えません。並 び替え中の外部からの読み出しについては並び替えには何の影 響も与えないので問題ありません。
