　リスト157　桁0のBCD値
 　  

if (RESET)
   degit0p=0;
else
   switch(ketacount)
      case 0:
         switch(convseq)
            case 4: degit0p=divans.0:3;
            default: degit0p=degit0p;
         endswitch
      default: degit0p=degit0p;
   endswitch
endif
 　 

主行程の 1 から 5 までを桁計数の ketacount を増やしながら ketacount が 7 になるまで繰り返していま す。桁 1 から桁 7 のBCD 値は digit1p から digit7p に記憶されます。これらの論理はほぼ同じで桁計数の ketacount の指定値が 1 から 7 になっているのが違うだけです。

図5.88　BCD値の最後の桁の取り出し
    　　　 

図5.88 は最後の桁のBCD 値を digit7p に記憶して主行程の convseq が 6 になって変換を終了したところです。

番地のADD に値を与えると リスト158 の dataout への代入によって digit0p から digit7p までの値を読み出すことができます。

　リスト158　BCD 値の出力
 　  

switch(ADD)
   case 0: dataout=degit0p;
   case 1: dataout=degit1p;
   case 2: dataout=degit2p;
   case 3: dataout=degit3p;
   case 4: dataout=degit4p;
   case 5: dataout=degit5p;
   case 6: dataout=degit6p;
   case 7: dataout=degit7p;
endswitch
