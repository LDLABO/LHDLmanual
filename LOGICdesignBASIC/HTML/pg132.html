　　　機能キー有効

　リスト132　
 　  

if (RESET)
   set=0;
else
   if (setkey)
      switch(keydata)
         case 4:  set=1;   { = }
         case 15: set=1;   { * }
         case 14: set=1;   { / }
         case 13: set=1;   { + }
         case 8:  set=1;   { - }
         default: set=set;
      endswitch
   else
      if (TAKE)
         set=0;
      else
         set=set;
      endif
   endif
endif
 　 

リスト132 の set は数値キー以外の機能キーが押されたことを示 します。機能キーは 図5.62 のような順番で押されます。

図5.62　機能キー
    　　　 

機能キーが押されたときはメモリには書き込みませんが次の数値 キーの入力に備えて外にメモリの内容を読み取らせてから初期化し ておく必要があります。


　　　機能種別

リスト133 の opcode は出力の FUNC に代入されて機能キーの種別を示します。

　リスト133　機能種別
 　  

if (RESET)
   opcode=0;
else
   if (setkey)
      switch(keydata)
         case 4:  opcode=1;   { = }
         case 15: opcode=2;   { * }
         case 14: opcode=3;   { / }
         case 13: opcode=4;   { + }
         case 8:  opcode=5;   { - }
         case 12: opcode=0;   { C }
         default: opcode=opcode;
      endswitch
   else
      if (TAKE)
         opcode=0;
      else
         opcode=opcode;
      endif
   endif
endif
 　 
　　　キー入力起点

リスト134 の setkeyp はキーの入力された起点を示します。 図5.63 が行程です。

　リスト134　キー入力起点
 　  

if (RESET)
   setkeyp=0;
else
   switch(setkeyp)
      case 0: 
         if (setkey) setkeyp=1; endif
      case 1:
         setkeyp=2;
      case 2:
         if (setkey)
            setkeyp=setkeyp;
         else
            setkeyp=0;
         endif
   endswitch
endif
