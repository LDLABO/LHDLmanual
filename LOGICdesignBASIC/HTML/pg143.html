　　2進数からBCDへの変換

32 ビットの2 進数から8 桁のBCD に変換する論理を作ります。32 ビットの2 進数を10 で割って、その余 りをBCD のひと桁として取り出します。そして、その商を新たな被除数としてこれを8 回繰り返すと下の桁か ら8 桁のBCD 値を得ることができます。


　　　チップ概観

図5.79　チップ概観
    　　　 

チップの概観は 図5.79 のようになります。

  • RESET : チップを初期化します。
  • ADD[3] : DATAOUT[4] に出力するBCD 値の桁を指定します。
  • DATAIN[32] : 2 進数のデータを入力します。
  • WP : 2 進数のデータの書き込み指標です。
  • DATAOUT[4] : ADD[3] で指定された桁のBCD 値です。
  • SET : 32ビットの2進数のデータを8桁のBCD値に変換できたことを示します。

　　32 ビット除算器

2進数BCD変換器で使う32ビットの除算器を作ります。

　　　チップ概観


図5.80　チップ概観
    　　　 

チップの概観は 図5.80 のようになります。

  • RESET : チップを初期化します。
  • A[32] : 被除数を示します。
  • B[32] : 除数を示します。
  • SEL : Y[32] に出力する商と余りを選択します。
  • Y[32] : SEL が0 のときは商を1 のときは余りを出力します。
  • READY : 除算の終了を示します。
　　32ビット除算器の論理

「本稿3.5 除算器」 の8 ビットの除算器と同じものですが リスト148 のように32 ビットに拡張して商と余りの選択ができるようにしてあります。ビット数が8 ビットから32 ビットになったので除算の終了は 9CLK から 33CLK になります。実行の様子は 図5.81 のようになります。
