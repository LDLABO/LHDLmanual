　　　追加命令のマクロ

　リスト56　追加命令のマクロ
 　  

;     CP r0,n
macro     CP R,NUMBER
   db 19,#0,#1&0ffh,0
endm

;    SLA r0,n
macro     SLA R,NUMBER
   db 27,#0,#1&0ffh,0
endm

;    SRL r0,n
macro     SRL R,NUMBER
   db 29,#0,#1&0ffh,0
endm
 　 

表4.2 の CP と SLA と SRL の命令を追加するマクロが リスト56 です。3 個ともレジスタ枠 0 は レジスタR をレジスタ枠 1 は即値の NUMBER を示します、レジスタ枠 2 は使っていません。マクロファイルが ppu.mac でアセンブリ言語のファイルが test.asm でアセンブルリストを出力させる場合に -L を付ける AASM -Mppu.mac -L test.asm のコマンドを実行するとインテルへクスデータのファイルの test.hex とアセンブルリストの test.lst が出力されます。
