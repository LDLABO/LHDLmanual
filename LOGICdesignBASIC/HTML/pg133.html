No.133
　
　　　端末の検証

端末にはキーボードと表示器がつながっています、キーボードからの入力によって端末のメモリにデータが書 き込まれます。メモリに書き込まれたデータは表示器に表示されます、また外からの操作によって読み出しも行 われます。表示器は端末に対しての入力はないので端末の表示器に対する出力を確認するだけです。端末を動か すためには検証論理がキーボードの役割を担って検証を進めていきます。


図5.64　検証手順
    　　　 

　　　検証手順

端末の論理に対応するキーボードの役割を検証論理に書いて 図5.64 のキーを押したようにします。そして次のようなことを確認します。

  • ①　端末のメモリにキーボードから 1 から 8 を書き込みます。この後に外から番地 0 から番地 7 の値を読み出してキーボードから入力されたデータとメモリに書き込まれたデータが合っているかを確認します。
  • ②　キーボードから+ を入力すると外に対してデータがあることが知らされるのでこれに応答します。応答 するとメモリの全ての値は0 になりますのでこれを確認します。
  • ③　1 番目のキーボードの入力で使わなかった数値を使って端末のメモリに書き込みを行います。これも前回 と同じように読み出しを行って確認します。
  • ④　キーボードから = を入力すると外に対してデータがあることが知らされますがここでは応答しません。
  • ⑤　キーボードから - を入力するとメモリの全ての値を0 にして外に知らせますのでこれを確認します。
  • ⑥　キーボードから C を入力すると端末は外に知らせますのでこれを確認します。
  • ⑦　キーボードから / を入力すると端末は外に知らせますのでこれを確認します。
  • ⑧　キーボードから * を入力すると端末は外に知らせますのでこれを確認します。
　　検証論理
　　　データ読み取り起点

リスト136 の takep は node_OFF が 1 になってキーが離されたときに起点を出します。

　リスト136　データ読み取り起点
 　  

if (node_RESET)
   takep=0;
else
   switch(takep)
      case 0: if (node_OFF) takep=1; endif
      case 1: takep=2;
      case 2:
         if (node_OFF)
            takep=takep;
         else
            takep=0;
         endif
   endswitch
endif
