　　　整列の確認

リスト31 は並び替えによって10 個のメモリのデータが小さい順番に整列しているかどうかを調べます、 図3.38 が整列の確認の実行部分です。

　リスト31　整列の確認
 　  

if (reset)
   hit=0;
else
   if (exec)
      if ((state==1)&(point==8))
         switch(hit)
            case 0: hit=2;    { b }
            case 1: hit=0;    { 1a }
            case 2: hit=hit;
         endswitch
      else
         if (chg)
            hit=1;            { a }
         else
            hit=hit;
         endif
      endif
   else
      hit=0;                  { 2a }
   endif
endif
 　 

図3.37 の hit の行程の意味は次のようになります。

  • 0 : メモリのデータの交換はまだ行われていない
  • 1 : メモリのデータの交換を実施した
  • 2 : 整列を完了した
  • a : メモリのデータの交換を指示した
  • b : 巡回中にメモリのデータの交換がなかった
  • 1a : もう一巡する
  • 2a : 比較交換の終わりを指示
  • 2b : 整列が崩れた
  • メモリの巡回中に交換があれば a に動きます。
  • メモリを一巡した後にメモリのデータの交換が1 度でも行われていると 1a に交換が行われて いなければ b に動きます。
  • 整列を完了していれば行程2 にとどまります。
  • いったん整列を完了しても外部からのメモリへ の書き込みで整列が崩れると 2b に動いて並び 替えを行います。
