No.127
　
　　　メモリと表示器への論理の追加

図5.56 表示
    　　　 

電卓の初期の表示は 図5.56 の A のようにメモリのすべての番地の値が0 のときは最下位の桁だけが0 を表示するよう にしたいと思います。キーが押されれば 図5.56 の ② から ⑨ ように表示がせり上がってくるようにします。このときも上位 の桁の値が0 のときは点灯させないようにしたいと思います。

最下位の桁はいつも点灯させるので不点灯を行う対象は 2 番目の桁から 8 番目の桁になります。不点灯させるためには各番 地のメモリ値が0 かどうかを知る指標を作ります。

 　  

switch(memory1)
   case 0: memoryzeq.1=1;
endswitch
 　 

メモリの番地1 の値を memory1 とするとその値が0 なら memoryzeq.1 が1 になります。このような信号をすべての番 地について memoryzeq.0〜7 に作ります。

図5.56 の ① から ⑨ の不点灯位置の情報を3 ビットの blank 信号に リスト124 のように符号化します。

① blank=1; ④ blank=3; ⑦ blank=6;
② blank=1; ⑤ blank=4; ⑧ blank=7;
③ blank=2; ⑥ blank=5; ⑨ blank=0;

blank 信号はメモリの論理に追加します。



　リスト124　メモリのblank
 　  

switch (memoryzeq.1:7)
   case 0b1111111: blank=1;
   default:
      switch (memoryzeq.2:7)
         case 0b111111: blank=2;
         default:
            switch(memoryzeq.3:7)
               case 0b11111: blank=3;
               default:
                  switch(memoryzeq.4:7)
                     case 0b1111: blank=4;
                     default:
                        switch(memoryzeq.5:7)
                           case 0b111: blank=5;
                           default:
                              switch(memoryzeq.6:7)
                                 case 0b11: blank=6;
                                 default:
                                    switch(memoryzeq.7)
                                       case 1: blank=7;
                                    endswitch
                              endswitch
                        endswitch
                  endswitch
            endswitch
      endswitch
endswitch
 　 

表示器の論理ではメモリの blank 信号を受けて リスト125 の8 ビットの blankketa 信号を作ります。

　リスト125　表示器のblankketa
 　  

switch(blank)
   case 0: blankketa=0b00000000;
   case 1: blankketa=0b11111110;
   case 2: blankketa=0b11111100;
   case 3: blankketa=0b11111000;
   case 4: blankketa=0b11110000;
   case 5: blankketa=0b11100000;
   case 6: blankketa=0b11000000;
   case 7: blankketa=0b10000000;
endswitch
 　 

blankketa 信号は下位のビットが下位の桁、上 位のビットが上位の桁の不点灯を示します。該当す るビットが1 ならその桁は不点灯、0 なら点灯です。
