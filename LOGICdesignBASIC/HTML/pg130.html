No.130
　
　　　キーボードの論理の修正

端末の論理のメモリの初期化の memclr で使った OFF はキーボードでキーがひとつも押されていないことを示す信号です。 memclr では C キーが離されたことを知るために使っています。 C キーが押されることで行 程を開始して C キーが離されるのを待って開始位置に戻ります。

このようにキーが押されたことは分かるが離されたことが分からないのでは問題があるのでキーボードの論理 を修正して OFF を追加します。修正前のキーボードの論理ではキーを押したままなら列駆動が巡回してくるた びに SET が 1 になっていてキーボードの論理でもキーが離されたことの認識ができていなかったので主行程の set を修正してキーが離されないと元の行程に戻らないようにします。


図5.60 修正後のキーボードの主行程
    　　　 

リスト130 が修正後のキーボードの論理です。 図5.60 が修正後のキーボードの行程です。キーが押されていないことの判定は各列で各行にキーが押されていないことを全列で確認できたときにキーが離されたと認識しま す。 図5.60 の行程の 2〜5 でキーが離されたことの確認をしています。行程が 0 のときに OFF を 1 にします。

　リスト130　修正後のキーボードの主行程
 　  

if (RESET)
   set=0;
else
   switch(set)
      case 0:
         if (sclkp.0)
            if (keypush)
               set=1;
            endif
         endif
      case 1:
         if (TAKE)
            set=2;
         else
            set=set;
         endif
      case 2:
         switch(count)
            case 0:
               switch(YIN)
                  case 0: set=3;
                  default: set=set;
               endswitch
            default: set=set;
         endswitch
      case 3:
         switch(count)
            case 1:
               switch(YIN)
                  case 0: set=4;
                  default: set=2;
               endswitch
            default: set=set;
         endswitch
      case 4:
         switch(count)
            case 2:
               switch(YIN)
                  case 0: set=5;
                  default: set=2;
               endswitch
            default: set=set;
         endswitch
      case 5:
         switch(count)
            case 3:
               switch(YIN)
                  case 0: set=0;
                  default: set=2;
               endswitch
            default: set=set;
         endswitch
   endswitch
endif
