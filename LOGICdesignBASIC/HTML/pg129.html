　リスト128　キー符号の数値への変換
 　  

switch(keydata)
   case 0:  data=0;
   case 1:  data=1;
   case 5:  data=2;
   case 9:  data=3;
   case 2:  data=4;
   case 6:  data=5;
   case 10: data=6;
   case 3:  data=7;
   case 7:  data=8;
   case 11: data=9;
   from:
      if (setkeyp.0) memset=1; endif
endswitch
 　 

リスト128 の data はキー符号の keydata を数値に変換したメモリへの「せり上がり書き込み」の書き込み値です。 memset はメモリへの「せり上がり書き込み」の書き込み指標 です。


　　　メモリ初期化

　リスト129　メモリ初期化
 　  

if (RESET)
   memclr=1;
else
   switch(memclr)
      case 0:
         if (TAKE)
            memclr=1;
         else
            switch(setkey,keydata)
               case 1,12: memclr=1;
            endswitch
         endif
      case 1:
         memclr=2;
      case 2:
         if (OFF)
            memclr=0;
         else
            if (TAKE)
               memclr=memclr;
            else
               memclr=0;
            endif
         endif
   endswitch
endif
 　 

リスト129 の memclr はメモリ初期化の行程を 図5.59 のように示しています。 memclr が 行程1 のときにメモリを初期化します。

図5.59 メモリ初期化の行程
    　　　 

setkey が 1 で keydata が 12 のときに C キーが押されたと認識します。 OFF が 1 のとき C キーは離されたと認識します。

TAKE が 1 になったときはメモリの内容が読み取られて初期 化が可能になったと認識します。
