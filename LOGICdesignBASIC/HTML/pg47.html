　　　レジスタX

レジスタX はメモリの番地を指定するレジスタとして作りました。 リスト37 の regX は レジスタX の値を記憶しています。

　リスト37　レジスタX
 　  

if (reset)
   regX=0;
else
   switch(codec)
      case 4:  regX=coded;   { LD  X,d8  }
      case 15: regX=regX+1;  { INC X     }
      case 21: regX=regA;    { LD  X,A   }
      case 25: regX=regX-1;  { DEC X     }
      case 28: regX=datain;  { LD  X,(X) }
      default: regX=regX;
   endswitch
endif

　　　フラグ

フラグは演算の結果の桁上がりを示す C と演算の結果が0 になったことを示す Z があります。これらのフラ グに演算の結果を記憶するのは後で分岐命令に利用するためです。
