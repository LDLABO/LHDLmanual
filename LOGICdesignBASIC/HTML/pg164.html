　　　計算の終了

　リスト179　計算終了指標
 　  

switch(execop)
   case 0: opend=1;
   case 2: opend=mulready;
   case 3: opend=divready;
   case 4: opend=answer.32;
   case 5: opend=answer.32;
endswitch
 　 
　リスト180　計算結果
 　  

switch(execop)
   case 2: answer=mulans;
   case 3: answer=divans;
   case 4: answer=regA+regB;
   case 5: answer=regA-regB;
endswitch
 　 

リスト179 の計算終了指標の opend は計算が終了したことを示します。 execop が 0 のときのように計算が行われない場合は 1 を代入しています。 execop が 0 以外のときは対応する計算の終了指標を代入しています。乗算の終了指標は mulready です。除算の終了指標は divready です。加算と減算は演算子を利用しているので確定ビットを代入しています。 リスト180 の計算結果の answer は execop で示される計算の結果を示します。乗算結果は mulans です。除算結果は divans です。


図5.118　計算の終了
    　　　 

　リスト181　レジスタA
 　  

if (RESET)
   regA=0;
else
   switch(calcseq)
      case 4:
         switch(execop)
            case 0: regA=regB;
            case 2: regA=answer;

            case 4: regA=answer;

   endswitch

　リスト182　レジスタB
 　  

if (RESET)
   regB=0;
else
   if (setseq.1)
      regB=bin;
   else
      switch(calcseq)
         case 4:  regB=0;
         default: regB=regB;
      endswitch
   endif
endif
 　 

図5.118 は 12345678/90= を実行しているところです。 regA に 12345678 が記憶されています。 regB に 90 が記憶されています。主行程の calcseq が 3 のときは計算を実行中ですが execop が 3 なので、その計算は除算になります。 divready が 0 から 1 になったときに除算を終了しています。このとき除算結果の divans から計算結果の answer に値を記憶しています。
