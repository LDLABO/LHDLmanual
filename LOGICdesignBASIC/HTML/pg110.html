図5.30 全体の表示行程
    　　　 

　　　主行程

リスト104 の主行程の state は 図5.31 のように一桁分の消灯から点灯への行程です。 図5.30 の全体の行程は主行程の繰り返しです。

図5.32 主行程
    　　　 

SCLK が0 から1 に変わったときに state を1 から0 にして消灯の行程に入ります。 blankcount が6 になったときに state を0 から1 にして点灯の行程に入ります。これらの様子は 図5.32 を見て下さい。

　リスト104　主行程
 　  

if (RESET)
   state=0;
else
   if (blankcount==6)
      state=1;
   else
      if (sclkp.0)
         state=0;
      else
         state=state;
      endif
   endif
endif
