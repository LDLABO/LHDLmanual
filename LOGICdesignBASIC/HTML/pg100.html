　　　キーデータ

keypush が1 のときに リスト97 で行データが リスト98 で列データが data に記憶されます。 data は Q に代入されます。

　リスト97　行データ
 　  

if (RESET)
   data.0:1=0;
else
   if (keypush)
      if (YIN.0)
         data.0:1=0;
      else
         if (YIN.1)
            data.0:1=1;
         else
            if (YIN.2)
               data.0:1=2;
            else
               if (YIN.3)
                  data.0:1=3;
               endif
            endif
         endif
      endif
   else
      data.0:1=data.0:1;
   endif
endif
 　 

同一の列にある行のスイッチが複数押されたときは1 個 以上の端子が高電位になります。このとき リスト97 の行データは YIN.0 を高位の優先度、 YIN.3 を低位の優先度にして、より高位のスイッチが1 個だけ押されたよ うに記憶します。

　リスト98　列データ
 　  

if (RESET)
   data.2:3=0;
else
   if (keypush)
      data.2:3=count;
   else
      data.2:3=data.2:3;
   endif
endif
 　 

　　キーボードの検証

キーボードとその論理の概観は 図5.15 のようになっています。これにキーが押されたり離されたりする検証 のための論理を追加して設計した論理を検証します。

図5.14 キーボードの検証対象
    　　　 

検証のための論理は 図5.11 のように Q が 0 から始まって 1〜15 になるようにスイッチを押していくように作ります。最初のほうの様子は 図5.16 のようになります。
