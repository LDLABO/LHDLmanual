　　　立ち上がりで記憶

図3.16 の記憶信号の p にあたる リスト17 の p.0&!p.1 によって記憶位置を P が0 から1 になっ たところにします。

　リスト17　立ち上がり計数器
 　  

entity main
input  RESET;
input  P;
output Q[8];

bitr q[8];
bitr p[2];

   Q=q;

   p.0=P;
   p.1=p.0;

   if (RESET)
      q=0;
   else
      if (p.0&!p.1)
         q=q+1;
      else
         q=q;
      endif
   endif

　　　立ち下がりで記憶

図3.16 の記憶信号のp にあたる リスト18 の !p.0&p.1 によって記憶位置を P が1 から0 に なったところにします。

　リスト18　立下り計数器
 　  

entity main
input  RESET;
input  P;
output Q[8];

bitr q[8];
bitr p[2];

   Q=q;

   p.0=P;
   p.1=p.0;

   if (RESET)
      q=0;
   else
      if (!p.0&p.1)
         q=q+1;
      else
         q=q;
      endif
   endif
