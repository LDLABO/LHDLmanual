　　2進数BCD変換器の論理

　リスト151　主行程
 　  

if (RESET)
   convseq=0;
else
   switch(convseq)
      case 0:
         if (WP) convseq=1; endif
      case 1:
         convseq=2;
      case 2:
         if (divready)
            convseq=3;
         else
            convseq=convseq;
         endif
      case 3:
         convseq=4;
      case 4:
         convseq=5;
      case 5:
         switch(ketacount)
            case 7: convseq=6;
            default: convseq=1;
         endswitch
      case 6:
         convseq=convseq;
   endswitch
endif
 　 

リスト151 の convseq は2進数BCD 変換器の主行程を示します。主行程の行程図は 図5.86 のようになります。

図5.85　主行程の出だし部分
    　　　 

主行程の出だし部分の 図5.85 では2進数の8ビット値を DATAIN に用意して WP を 1 にすると convseq が 0 から 1 になって行程が進みはじめます。 convseq が 1 のところで リスト154 の divreset が 1 になるので除算器が初期化されて 12345678 ÷ 10 の計算が開始されます。 convseq が 2 のところは計算を実行中です。

図5.87　BCD 値のひと桁の取り出し
    　　　 

除算終了の divready が 1 になって除算が終了すると主行程の convseq は 2 から 3 になります。主行程が 3 のところ では次の計算に備えて現在の商の divans が新しい被除数として リスト153 の a に記憶されます。主行程が 4 のところで商と余りの切り替えの リスト155 の sel が 1 になって divans に余りが表れるので桁計数の リスト156 の ketacount の指定する リスト157 の digit0p に 図5.87 のように記憶します。主行程が 5 のところで桁計数の ketacount を更新しています。また、このとき桁計数の ketacount が 7 であれば主行程は 6 に進みます。 7 以外であれば 1 に戻ります。
