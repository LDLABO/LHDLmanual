図5.38 機能実行
    　　　 

　　　機能実行

図5.38 は機能実行の一部分を抜粋したものです。全部は SIM06E09A.pdf を見て下さい。見出しが黄色の信号は機能実行譜に書かれている検証論理で使っています。

  • count が 0 の間は KETA と DATA は同じ値ですが count が 1 以上の値のときは DATA は KETA に count を加算した値になります。
  • blankcount が 0〜6 の間が消灯期間です。消灯期間に KETAOUT が 0 になって全桁が消灯されています。
  • DATA が 7 のとき SEGOUT が 7 、 DATA が 0 のとき SEGOUT が 7f 、 DATA が 1 のとき SEGOUT が 6 になっているのは設計の通りです。
