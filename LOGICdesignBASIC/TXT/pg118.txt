<p class="i">
<font color="red">リスト113</font> 
の
<font color="blue">memory0～memory7</font> 
はメモリの手続きを引用して8 個のメモリを構成したものです。
<font color="blue">we</font> 
は書き込み行程の
<font color="blue">wp</font> 
が
<font color="red">3</font> 
の書き込み実行のときに
<font color="red">1</font> 
になります。
</p>

<br clear="right">

<hr color="#6666CC" size="10">
<font size="4" color="#5454AB"><b>　　　書き込み行程</b></font><br>
<hr color="#6666CC">

<br>

<table align="right">
<a name="LST114"></a>
<caption><font color="red">　リスト114</font>　書き込み行程</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
if (RESET)
   wp=0;
else
   switch(wp)
      case 0:
         switch(WP,WCP)
            case 0,0: wp=0;
            case 1,0: wp=1;   { せり上がり書き込み }
            case 0,1: wp=2;   { 番地指定書き込み }
            case 1,1: wp=2;   {   〃　 }
         endswitch
      case 1: wp=3;   { せり上がり書き込み行程選択 }
      case 2: wp=3;   { 番地指定書き込み行程選択 }
      case 3: wp=0;   { 書き込み実行 }
   endswitch
endif
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト114</font> 
の
<font color="blue">wp</font> 
は書き込み行程を示します。
書き込み行程は
<font color="blue">WP</font> 
と
<font color="blue">WCP</font> 
のどちらかで起動されます。両方で同時に起動された場合は
<font color="blue">WCP</font> 
で起動されたとみなします。
</p>

<p class="i">
<font color="red">リスト115</font> 
の
<font color="blue">mode</font> 
は書き込み行程の
<font color="blue">wp</font> 
が
<font color="blue">3</font> 
の書き込み実行のときの書き込み種別を示します。書き込み種別は「せり上がり書き込み」と「番地指定書き込み」です。書き込み種別は書き込み行程の
<font color="blue">wp</font> 
が
<font color="blue">1</font> 
になったときは「せり上がり書き込み」になります。書き込み行程の
<font color="blue">wp</font> 
が
<font color="blue">2</font> 
になったときは「番地指定書き込み」になります。実行の様子は「せり上がり書き込み」が選択されたときは
<font color="red">図5.46</font> 
です。「番地指定書き込み」が選択されたときは
<font color="red">図5.47</font> 
です。
</p>
