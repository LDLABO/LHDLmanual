<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
logicname bcdconvled

library bcdconv        { BCD変換器 ライブラリ }
library led7dspdyd     { LED表示器 ライブラリ }

entity main
input RESET;               { 初期化 }
input SCLK;                { 桁駆動CLK }
input REQ;                 { 変換要求 }
input ADATA[8];            { データ }
output LED7SEG[7];         { セグメントデータ }
output KETA[3];            { 桁 }

bitn int_bcdconv[13];      { BCD変換器 手続き }
bitn int_led7dspdyd[10];   { LED表示器 手続き }
bitn bcd0p[4];             { BCD 第1桁 }
bitn bcd1p[4];             { BCD 第2桁 }
bitn bcd2p[4];             { BCD 第3桁 }
bitn we;                   { BCD書き込み }
bitn led7seg[7];           { セグメントデータ }
bitn keta[3];              { 桁 }

   LED7SEG=led7seg;
   KETA=keta;

   int_bcdconv=bcdconv(RESET,REQ,ADATA);

   int_bcdconv.13=1;

   bcd0p=int_bcdconv.0:3;
   bcd1p=int_bcdconv.4:7;
   bcd2p=int_bcdconv.8:11;
   we=int_bcdconv.12;

   int_led7dspdyd=led7dspdyd(RESET,SCLK
                 ,bcd0p,bcd1p,bcd2p,we);

   int_led7dspdyd.10=1;

   led7seg=int_led7dspdyd.0:6;
   keta=int_led7dspdyd.7:9;

ende
endlogic
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>

<p class="i">
これまでに論理設計で作ったBCD 変換器とLED 表
示器を手続きにしてライブラリを作ります。このライ
ブラリから手続きを引用してふたつの論理設計をひと
つにまとめます。
</p>

<p class="i">
BCD 変換器とLED 表示器を手続きにしてひとつの論理譜にしたのが
<font color="red">リスト62</font> 
です。これを
<font color="blue">XC95144</font> 
でワンチップにしたものが
<font color="red">リスト63</font> 
です。この論理譜に引用した論理は次のファイルを参照して下さい。
</p>

<ul>
<li class="i">
BCD 変換器手続き: 
<a href="../LIB/pro_bcdconv.l" target="_blank">
<font color="blue">pro_bcdconv.l</font>
</a>
</li>

<li class="i">
LED 表示器手続き: 
<a href="../LIB/pro_led7seg.l" target="_blank">
<font color="blue">
pro_led7dspdyd.l
</font>
</a>
</li>

<li class="i">
BCD 変換器ライブラリ: 
<a href="../LIB/bcdconv.lib" target="_blank">
<font color="blue">
bcdconv.lib
</font>
</a>
</li>

<li class="i">
LED 表示器ライブラリ: 
<a href="../LIB/led7dspdyd.lib" target="_blank">
<font color="blue">
led7dspdyd.lib
</font>
</a>
</li>
</ul>

<p class="i">
論理を手続きにして引用して使うことで論理設計を
階層化することができます。手続きのあるライブラリ
ファイルの導入はBCD 変換器については
</p>

<pre class="i">
<font face="Lucida Console" color="#CC0000" size="2">
library bcdconv
</font>
</pre>

<p class="i">
のように書きます。
<font color="blue">bcdconv</font> 
はライブラリファイルの
名前です、今回は手続きをひとつだけ入れたライブラ
リを使っていますがライブラリには複数の手続きが入
ります。このライブラリの中から手続きを引用するに
は次のように書きます。
</p>

<pre class="i">
<font face="Lucida Console" color="#CC0000" size="2">
int bcdconv=bcdconv(RESET,REQ,ADATA)
</font>
</pre>

<p class="i">
<font color="blue">bcdconv</font> 
が手続き名でこの名前をライブラリの中か
ら探し出して論理に展開しています。
</p>
