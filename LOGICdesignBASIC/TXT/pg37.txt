<table align="right">

<caption><font color="red">　リスト27</font>　比較交換行程</caption>

<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
if (reset)
   state=0;
else
   if (exec)
      if (stateend)
         state=0;
      else
         state=state+1;
      endif
   else
      state=0;
   endif
endif
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト27</font> 
の
<font color="blue">state</font> 
の比較交換行程はメモリのデータの比較とメモリ
のデータの交換の2 行程です。
</p>

<ul class="i">
<li class="i">
<font color="blue">state</font> 
が0 : 二つのメモリのデータを比較する行程です。
</li>

<li class="i">
<font color="blue">state</font> 
が1 : 二つのメモリのデータを交換する行程です。
また比較交換行程の終わりです。
</li>
</ul>

<p class="i">
<font color="red">リスト28</font>

</p>

<ul class="i">
<li class="i">
<font color="blue">state0p</font> 
が1 : 二つのメモリのデータを比較する位置です。
</li>

<li class="i">
<font color="blue">state1p</font> 
が1 : 二つのメモリのデータを交換する位置です。
</li>

<li class="i">
<font color="blue">stateend</font> 
が1 : 比較交換行程の終わりを示す位置です。
</li>
</ul>
