<p class="i">
計数器とかシフトレジスタとか時間を追って動くものに使う論理設計には欠かせないものです。ここでいう記
憶とは
<font color="red">図3.16</font> 
の同期式の論理設計を前提にしています。いつ記憶するのかを
<font color="blue">p</font> 
に何を記憶するのかを
<font color="blue">d</font> 
に設計
します。
</p>

<table align="right">
<a name="LST14"></a>
<caption><font color="red">　リスト14</font>　1 ビットの記憶</caption>
<tr>
<td >&nbsp;　　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
entity main
input  RESET;
input  P;
input  D;
output Q;

bitr q;

   Q=q;

   if (RESET)
      q=0;
   else
      if (P)
         q=D;
      else
         q=q;
      endif
   endif

ende
</font>
</pre>
</td>
<td >&nbsp;　　　　　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト14</font> 
が
<font color="red">図3.16</font> 
の最も簡単な例です
<font color="blue">bitr q</font> 
が記憶信号であることを示
します。
</p>

<p class="i">
<font color="red">図3.17</font> 
が
<font color="red">リスト14</font> 
を実行したものです。
<font color="blue">P</font> 
は
1CLK 
だけ
1 
になっています
が1 点で記憶したい場合はこのような信号を使います。
<font color="blue">P</font> 
が1CLK 以上の信
号なら
<font color="blue">P</font> 
が1 の最後のCLK の
<font color="blue">D</font> 
の値で記憶します。
</p>
