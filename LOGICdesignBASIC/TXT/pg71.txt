<p class="i">
<font color="red">リスト72</font> 
のレジスタ
<font color="blue">R3</font> 
は作業用のレジスタでプログラムで自由に使うレジスタです。また
<font color="blue">SLA</font> 
命令は本レジスタだけで使うことのできる命令です。
<font color="blue">code27p</font>
が1 のときは
<font color="blue">SLA</font> 
命令が実行中であることを示しています。
</p>

<pre>
<font face="Lucida Console" color="#330099" size="2">
{ PPU レジスタR3 }
if (RESET)
   reg3R=0;
else
   if (code27p)          { SLA r3,n }
      switch(PORT0ADD)
         case 3:  reg3R=reg3R>>DATAIN.8:11;
         default: reg3R=reg3R;
      endswitch
   else
      if (RW)
         switch(PORT0ADD)
            case 3:  reg3R=PORT0OUT;
            default: reg3R=reg3R;
         endswitch
      else
         reg3R=reg3R;
      endif
   endif
endif
</font>
