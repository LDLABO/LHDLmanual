<font size="4" color="#5454AB"><b>　　　追加ライブラリ</b></font><br>
<hr color="#6666CC">

<br>

<table align="right">
<a name="LST164"></a>
<caption><font color="red">　リスト164</font>　追加ライブラリ</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
library LDL06F06A0 { 端末 }
library LDL06E21A  { BCD2進数変換器 }
library LDL06F04A  { 2進数BCD変換器 }
library LDL06E19A  { 乗算器 }
library LDL06F04B  { 除算器 }
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト164</font> 
は標準ライブラリに追加するライブラリを指定
しています。標準ライブラリの
<font color="blue">std.lib</font> 
に無い手続きを利用するときは、このように追加しておきます。
</p>

<br clear="right">

<hr color="#6666CC" size="10">
<font size="4" color="#5454AB"><b>　　　手続きの引用</b></font><br>
<hr color="#6666CC">

<br>

<table align="right">
<a name="LST165"></a>
<caption><font color="red">　リスト165</font>　手続きの引用</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
div=LDL06F04B(divreset,regA,regB,0);
mul=LDL06E19A(mulreset,regA,regB);
term=LDL06F06A(RESET,SCLK,YIN,add,take,addb,dspbcd,dspbcdwp);
change=LDL06E21A(changereset,data);
chgbintobcd=LDL06F04A(chgbintobcdres,regA,wp,addb);
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
各手続きの引用は
<font color="red">リスト165</font> 
のように行います。追加したライブラリの名前
と引用する手続きの名前が同じになって
いますが今回はこのようにしているだけ
で別々の名前にできます。
</p>

<br clear="right">

<hr color="#6666CC" size="10">
<font size="4" color="#5454AB"><b>　　　計算の種類</b></font><br>
<hr color="#6666CC">

<br>

<table align="right">
<a name="LST166"></a>
<caption><font color="red">　リスト166</font>　計算の種類</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
if (RESET)
   calcop=0;
else
   if (set)
      switch(func)
         case 1: calcop=1;   { = }
         case 2: calcop=2;   { * }
         case 3: calcop=3;   { / }
         case 4: calcop=4;   { + }
         case 5: calcop=5;   { - }
      endswitch
   else
      calcop=calcop;
   endif
endif
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト166</font> 
の
<font color="blue">calcop</font> 
は計算の種類を示しています。チップの初期化では
<font color="blue">calcop</font> 
は
<font color="blue">0</font> 
にされて、行うべき計算は示されません。端末の
<font color="blue">set</font> 
が
<font color="blue">1</font> 
で
<font color="blue">func</font> 
が
<font color="blue">1</font> 
から
<font color="blue">5</font> 
の値のときは端末で計算の種類を示すキーが押されているので
<font color="blue">calcop</font> 
は
<font color="blue">func</font> 
の値を計算の種類として記憶します。
</p>
