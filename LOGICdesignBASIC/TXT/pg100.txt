<hr color="#6666CC">

<p class="i">
<font color="blue">keypush</font> 
が1 のときに
<font color="red">リスト97</font> 
で行データが
<font color="red">リスト98</font> 
で列データが
<font color="blue">data</font> 
に記憶されます。
<font color="blue">data</font> 
は
<font color="blue">Q</font> 
に代入されます。
</p>

<table align="right">
<a name="LST97"></a>
<caption><font color="red">　リスト97</font>　行データ</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
if (RESET)
   data.0:1=0;
else
   if (keypush)
      if (YIN.0)
         data.0:1=0;
      else
         if (YIN.1)
            data.0:1=1;
         else
            if (YIN.2)
               data.0:1=2;
            else
               if (YIN.3)
                  data.0:1=3;
               endif
            endif
         endif
      endif
   else
      data.0:1=data.0:1;
   endif
endif
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
同一の列にある行のスイッチが複数押されたときは1 個
以上の端子が高電位になります。このとき
<font color="red">リスト97</font> 
の行データは
<font color="blue">YIN.0</font> 
を高位の優先度、
<font color="blue">YIN.3</font> 
を低位の優先度にして、より高位のスイッチが1 個だけ押されたよ
うに記憶します。
</p>
