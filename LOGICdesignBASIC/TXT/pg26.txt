<p class="i">
通信や除算などでよく使うシフトレジスタも
<font color="red">リスト15</font> 
のように
<font color="red">図3.16</font> 
の構成と同じです。
<font color="red">図3.16</font> 
のデータの
<font color="blue">d</font> 
が
<font color="red">リスト15</font> 
では入力の
<font color="blue">D</font> 
と前段の記憶素子の出力になっています。
<font color="red">図3.18</font> 
が
<font color="red">リスト15</font> 
を実行したもの
です。
</p>

<caption><font color="red">　リスト15</font>　シフトレジスタ</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
entity main
input  RESET;
input  P;
input  D;
output Q[8];

bitr q[8];

   Q=q;

   if (RESET)
      q=0;
   else
      if (P)
         q.0=D;
         q.1:7=q.0:6;
      else
         q=q;
      endif
   endif

ende
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<br clear="left"><br>

<p class="i">
データの
<font color="blue">d</font> 
の部分を変えることで下位のビットから上位のビットへの移動だけ
ではなくて逆に上位のビットから下位のビットへ移動させたりとか
<font color="blue">RESET</font> 
の他にも別の信号を設けてシフトレジスタに値を設定したりするとか多機能なシフト
レジスタにすることができます。
</p>
