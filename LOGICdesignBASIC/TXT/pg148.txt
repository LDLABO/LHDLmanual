<font color="#336633"><b>　　2進数BCD変換器の検証</b></font>
<hr color="#4F9177">

<br>

<table align="right">
<a name="LST159"></a>
<caption><font color="red">　リスト159</font>　機能実行譜</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
entity sim
output RESET;
output DATAIN[32];
output WP;
output ADD[3];
output DATAOUT[4];
output SET;

bitr   tc[10];

   part main(RESET,DATAIN,WP,ADD,DATAOUT,SET)

   tc=tc+1;

   if (tc<5) RESET=1; endif

   switch(tc)
      case 10: DATAIN=12345678; WP=1;
      case 11: DATAIN=12345678;
      case 12: DATAIN=12345678;
      case 13: DATAIN=12345678;
   endswitch

   switch(tc)
      case 320: ADD=7;
      case 321: ADD=6;
      case 322: ADD=5;
      case 323: ADD=4;
      case 324: ADD=3;
      case 325: ADD=2;
      case 326: ADD=1;
      case 327: ADD=0;
   endswitch
ende
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="red">リスト159</font> 
は2進数BCD変換器の検証論理です。
<font color="blue">DATAIN</font> 
に2進数のデータを用意して書き込み指標の
<font color="blue">WP</font> 
を
<font color="blue">1</font> 
にするとBCD値への変換が始まります。変換の終了した後で
<font color="blue">ADD</font> 
に番地を与えて8桁のBCD値を読み出します。
</p>

<p class="i">
検証論理は大部分を
<font color="blue">tc</font> 
の位置によって実行を進めています。変換終了後の結果を見るために
<font color="blue">ADD</font> 
に値を与えていますが、この
<font color="blue">tc</font> 
の位置が前もって分からない場合などは一回実行してから、その位置をつかみます。
</p>

<p class="i">
検証結果の
<font color="red">図5.88</font> 
は変換を終了してBCD 値を読み出しているところです。
</p>

<p class="i">
ModelSim によるものは一番下の桁を取り出したとこ
ろが
<font color="red">図5.89</font> 
で変換を終了したところが
<font color="red">図5.90</font> 
です。
</p>
