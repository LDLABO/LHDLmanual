<p class="i">
<font color="red">リスト52</font> 
はフラグ
<font color="blue">Z</font> 
の
<font color="blue">flgZ</font> 
を示します。
<font color="red">表4.1</font> 
の
<font color="blue">CP</font> 
命令
によってフラグ
<font color="blue">Z</font> 
を変更します。レジスタ
<font color="blue">0</font> 
の
<font color="blue">reg0R</font> 
と即値の
<font color="blue">PORT1ADD</font> 
を比較しています。
<font color="blue">CP r0,n</font> 
ではレジスタ枠1 に即値の
<font color="blue">n</font> 
が入りますから
<font color="blue">PORT1ADD</font> 
の値は即値の
<font color="blue">n</font> 
です。
</p>

if (RESET)
   reg0R=0;
else
   if (code27p|code29p)
      if (code27p) reg0R=reg0R＞＞PORT1ADD.0:3; endif
      if (code29p) reg0R=reg0R＜＜PORT1ADD.0:3; endif
   else
      if (RW)
         switch(PORT0ADD)
            case 0:  reg0R=PORT0OUT;
            default: reg0R=reg0R;
         endswitch
      else
         reg0R=reg0R;
      endif
   endif
endif
</font>
</pre>

<p class="i">
<font color="red">リスト53</font> 
はレジスタ
<font color="blue">0</font> 
の
<font color="blue">reg0R</font> 
を示し
ます。レジスタ
<font color="blue">0</font> 
を変更する命令指標は次
のものがあります。
</p>

<ul class="i">
<li class="i">
<font color="blue">code27p</font> : SLA r0,n
</li>

<li class="i">
<font color="blue">code29p</font> : SRA r0,n
</li>
</li>
</ul>

<p class="i">
レジスタ枠
<font color="blue">0</font> 
で示されるレジスタに対す
る書き込み指標は
<font color="blue">RW</font> 
です、この値が1 で
<font color="blue">PORT0ADD</font> 
の値が0 のときはレジスタ
<font color="blue">0</font> 
に
対する書き込みなのでレジスタ枠
<font color="blue">0</font> 
で示さ
れるレジスタへの書き込み値の
<font color="blue">PORT0OUT</font>
の値をレジスタ0 を示す
<font color="blue">reg0R</font> 
に記憶します。
</p>
