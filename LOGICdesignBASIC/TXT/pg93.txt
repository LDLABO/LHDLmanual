<hr color="blue" size="20">
<font color="blue">　電卓</font>
<hr color="blue">

<p class="i">
10 進数の四則演算を行う8 桁の計算器です、外観は
<font color="red">図5.1</font> 
のようになります。数値キーは
<font color="blue">0</font> 
から
<font color="blue">9</font> 
、演算キーは
<font color="blue">+-*/=</font> 
、その他に全初期化の
<font color="blue">AC</font> 
と置数初期化の
<font color="blue">C</font> 
があります。置数は
<font color="blue">1 2 3 4</font> 
と押したとき
<font color="red">図5.2</font> 
のようになります。整数のみを扱い少数は扱いません、また正数のみを前提として負数は扱いません。
</p>

<p class="i">
<font color="blue">1234+5678=</font> 
は次の手順で計算します。
</p>

<ol>
<li class="i">
<font color="blue">1234</font> 
の置数は4 ビット×8 のメモリにBCD 値
<a href="#*2"><font color="red">*1</font></a>
で記憶します。
</li>

<li class="i">
<font color="blue">+</font> 
の入力で演算の種類を記憶して先のBCD 値も32 ビットのバイナリ
値に変換して記憶します。
</li>

<li class="i">
<font color="blue">5678</font> 
の置数は4 ビット×8 のメモリにBCD 値で記憶します。
</li>

<li class="i">
<font color="blue">=</font> 
の入力で先のBCD 値を32 ビットのバイナリ値に変換して記憶します。
</li>

<li class="i">
記憶された2 個の32 ビット値を記憶された演算で処理し結果を表示し
ます。
</li>
</ol>

<p class="i">
これらを実行するための機能分割は次のようになります。
</p>

<ul>
<li class="i">
置数された数値をBCD で記憶する4 ビット×8 のメモリ。
</li>

<li class="i">
BCD 値をバイナリ値にするための変換器。
</li>

<li class="i">
2 個の32 ビット値を記憶するためのメモリ。
</li>

<li class="i">
バイナリ値をBCD 値にするための変換器。
</li>

<li class="i">
四則演算のための演算器。
</li>

<li class="i">
置数または結果を表示するための8 桁の表示器。
</li>

<li class="i">
置数または操作のためのキーボード。
</li>
</ul>

<p class="i">
これらは次のものに集約します。
</p>

<br clear="right">

<ul>
<li class="i">端末</li>
<li class="i">BCD→BIN 変換器</li>
<li class="i">BIN→BCD 変換器</li>
<li class="i">加算器</li>
<li class="i">減算器</li>
<li class="i">乗算器</li>
<li class="i">除算器</li>
<li class="i">レジスタ2 本</li>
</ul>
