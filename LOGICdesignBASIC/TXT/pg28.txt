<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
entity main
input  RESET;
input  P;
output Q[8];

bitr q[8];
bitr p[2];

   Q=q;

   p.0=P;
   p.1=p.0;

   if (RESET)
      q=0;
   else
      if (p.0^p.1)
         q=q+1;
      else
         q=q;
      endif
   endif

ende
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>

<p class="i">
<font color="red">図3.16</font> 
の記憶信号の
<font color="blue">p</font> 
にあたる
<font color="red">リスト19</font> 
の
<font color="blue">p.0^ p.1</font> 
によって記憶位置を
<font color="blue">P</font> 
が1 から0 になったところと
0 から1 になったところにします。
</p>

<p class="i">
これまで作ってきたように記憶によって動いている論理は
<font color="red">図3.16</font> 
の記憶信号の
<font color="blue">p</font> 
で決める記憶位置と
<font color="blue">d</font> 
で決める記憶するデータによって様々な動きを作ることができます。
</p>
