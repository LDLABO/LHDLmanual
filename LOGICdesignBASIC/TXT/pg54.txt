<font size="4" color="#666633"><b>　　　プログラムカウンタ</b></font><br>
<hr color="#CC9966">

<p class="i">
<font color="red">リスト43</font> 
はプログラムカウンタの論理です、プログラムカウンタは分岐命令がなければ
<font color="blue">regPC=regPC+1</font> 
になります。分岐命令があれば
<font color="blue">regPC=jmpcode</font> 
になります。割り込みがあったときは
<font color="blue">regPC.0:7=PORT0IN</font> 
になります。プログラムカウンタの動きは
<font color="red">図4.7</font> 
の
<font color="blue">ADDRESS</font> 
を見て下さい。
</p>

<table class="i" align="left">
<a name="LST43"></a>
<caption><font color="red">　リスト43</font>　プログラムカウンタ</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
if (RESET)
   regPC=0;
else
   if (INT)
      regPC.0:7=PORT0IN;
   else
      if (inst1no)                    { JP n'n }
         regPC=jmpcode;
      else
         if (inst2no)                 { JZ n'n }
            if (flgZ)
               regPC=jmpcode;
            else
               regPC=regPC+1;
            endif
         else
            if (inst10no)             { JNZ n'n }
               if (!flgZ)
                  regPC=jmpcode;
               else
                  regPC=regPC+1;
               endif
            else
               if (inst12no)          { LD pc,r0 }
                  regPC.0:7=PORT0IN;
               else
                  regPC=regPC+1;
               endif
            endif
         endif
      endif
   endif
endif
