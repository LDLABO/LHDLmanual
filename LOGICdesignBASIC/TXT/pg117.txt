<font face="Lucida Console" color="#330099" size="2">
1 : procedure MEMORY
2 : input  RESET;
3 : input  CS;
4 : input  WP;
5 : input  DATAIN[4];
6 : output DATAOUT[4];
7 : 
8 : bitr memory[4];
9 : 
10:    DATAOUT=memory;
11: 
12:    if (RESET)
13:       memory=0;
14:    else
15:       if (WP)
16:          if (CS)
17:             memory=DATAIN;
18:          else
19:             memory=memory;
20:          endif

22:          memory=memory;

24:    endif

</td>

<p class="i">
<font color="red">リスト111</font> 
は4 ビットのメモリの1 番地分を手続きに書いたものです。
電卓の8 桁の内の一桁のBCD 値を記憶します。行8 の
<font color="blue">memory[4]</font> 
がメモリの本体です。
</p>

<ul>
<li class="i">
<font color="blue">RESET</font> 
が
<font color="blue">1</font> 
のときに
<font color="blue">memory</font> 
を
<font color="blue">0</font> 
にします。
</li>

<li class="i">
<font color="blue">CS</font> 
と
<font color="blue">WP</font> 
が
<font color="blue">1</font> 
のときに
<font color="blue">memory</font> 
に
<font color="blue">DATAIN</font> 
を記憶します。
</li>
</ul>

<p class="i">
<font color="blue">行10</font> 
は記憶信号の
<font color="blue">memory</font> 
を出力の
<font color="blue">DATAOUT</font> 
に代入しています。
</p>

<table align="right">
<a name="LST112"></a>
<caption><font color="red">　リスト112</font>　メモリの機能実行譜</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
1 : entity sim
2 : output RESET;
3 : output CS;
4 : output WE;
5 : output DATAIN[4];
6 : output DATAOUT[4];
7 : 
8 : bitn node_DATAIN[4];
9 : bitn node_RESET;
10: bitn node_CS;
11: bitn node_WE;
12: bitr tc[8];
13: 
14:    RESET=node_RESET;
15:    CS=node_CS;
16:    WE=node_WE;
17:    DATAIN=node_DATAIN;
18: 
19:    DATAOUT=MEMORY(node_RESET,node_CS,node_WE
20:                  ,node_DATAIN);
21: 
22:    tc=tc+1;
23: 
24:   if (tc<5) node_RESET=1; endif
25: 
26:    switch(tc)
27:       case 10: node_CS=1; node_WE=1; node_DATAIN=5;
28:       case 13: node_CS=1; node_WE=1; node_DATAIN=6;
29:       case 16: node_CS=1; node_WE=1; node_DATAIN=7;
30:       case 19: node_CS=1; node_WE=1; node_DATAIN=8;
31:    endswitch
32: 
33: ende
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
<font color="blue">行19</font> 
が手続きを引用しているところです。
</p>

<p class="i">
<font color="blue">tc</font> 
の値を検証の位置として
<font color="blue">行26～31</font> 
でメモリに書き込みを行っています。
</p>

<ul>
<li class="i">
<font color="blue">行27 : </font>
5 の書き込み
</li>

<li class="i">
<font color="blue">行28 : </font>
6 の書き込み
</li>

<li class="i">
<font color="blue">行29 : </font>
7 の書き込み
</li>

<li class="i">
<font color="blue">行30 : </font>
8 の書き込み
</li>
</ul>

<p class="i">
手続きに入力される信号に出力端子を使うことはできないので例えば検証論理で
<font color="blue">RESET</font>
を操作する場合には
<font color="blue">RESET</font> 
は
<font color="blue">node_RESET</font> 
を使って
<font color="blue">RESET</font> 
に代入しています。
</p>

<p class="i">
<font color="red">リスト112</font> 
は手続きを検証する機能実行譜
の簡単な例ですが大きな検証論理を作るとき
にも検証論理のために手続きを引用して使う
こともできます。
</p>
