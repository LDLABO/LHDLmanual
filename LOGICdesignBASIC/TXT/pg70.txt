<hr color="#CC9966" size="10">
<font size="4" color="#666633"><b>　　　除算器</b></font><br>
<hr color="#CC9966">

<p class="i">
<font color="red">リスト69</font> 
の
<font color="blue">divout=divina/divinb</font> 
の部分は言語が演算子で提供する記憶形式の8 ビットの除算を使ってプロセッサの除算命令を実現しています。除算命令は
<font color="blue">DIV r0,n</font> 
なので入力
<font color="blue">a</font> 
はレジスタ
<font color="blue">R0</font> 
から入力
<font color="blue">b</font> 
は即値から値を持ってきます。
</p>

<table align="right">
<a name="LST69"></a>
<caption><font color="red">　リスト69</font>　除算の実行</caption>
<tr>
<td >&nbsp;　&nbsp;</td>
<td>
<pre>
<font face="Lucida Console" color="#330099" size="2">
{ PPU 除算器 }
if (!code23p)
   divout=divina/divinb;
endif

{ PPU 除算器入力a }
if (code23p)
   switch(PORT0ADD)
      case 0:  divina=PORT0IN;
      default: divina=divina;
   endswitch
else
   divina=divina;
endif

{ PPU 除算器入力b }
if (code23p)
   divinb=DATAIN.8:15;
else
   divinb=divinb;
endif

{ PPU 1 レジスタFE }
flgE=divout.8;
</font>
</pre>
</td>
<td >&nbsp;　&nbsp;</td>
</tr>
</table>

<p class="i">
この論理を実行した様子が
<font color="red">図4.23</font> 
です。
<font color="blue">code23p</font> 
が1 のときに除算器が初期化されて13 個のCLK を使って
<font color="blue">divout.8</font> 
が1 のときに結果が出ています。
</p>
